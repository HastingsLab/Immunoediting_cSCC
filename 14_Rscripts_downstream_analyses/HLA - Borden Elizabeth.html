df <- read_csv("hla_a_supertypes_raw_numbers_by_group(in).csv") %>% 
      select(-`...1`) %>%
      # Convert long data into contigency table
      pivot_wider(names_from = immune,

Fisher’s exact test was used on this 5×3 table to test whether the distribution of HLA-A supertypes differed across immune groups, since some cell counts were less than 5. The overall p = 0.82 indicated no significant difference.

Residual plots

Residuals show how much the actual counts of HLA-A supertypes differ from what we would expect if the distribution were the same across all immune groups. Positive values mean more than expected, negative values mean fewer. The dashed red lines at ±2 are the usual cutoff for what we’d consider a “large” difference. Since all the bars stay within these red lines, the differences we see are small and not strong enough to be meaningful. For example, the A03 type looks a little higher in the High group, but it’s still within the range of normal variation, it’s more likely due to random variation in your current sample.

Show the code 
# Residual plot
chi <- chisq.test(df)
res <- as.data.frame(as.table(chi$residuals))
names(res) <- c("Supertype", "Group", "StdResid")

ggplot(res, aes(x = Group, y = StdResid, fill = StdResid)) +
  geom_col() +
  facet_wrap(~Supertype, nrow = 1) +
  geom_hline(yintercept = c(-2, 2), linetype = "dashed", color = "red") +
  labs(title = "Standardized residuals by supertype and group",
       y = "Standardized residual") +
  scale_fill_gradient2(midpoint = 0) +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1, size = 8,face = "bold"))
